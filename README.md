# Smooth Cursor

Chrome 拡張機能。ページ上のマウスカーソルをなめらかに動かし、実際に通った道筋どおりにモーションブラーをかけます。

## 入れ方

1. このリポジトリをダウンロードして展開する。
2. `chrome://extensions` を開き、右上のデベロッパーモードをオンにする。
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選ぶ。
4. 開いていたタブは一度再読み込みする。

Chrome 128 以降が必要です。

## 設定

ツールバーのアイコンから開きます。変更は開いているタブにすぐ反映されます。

| 項目 | 内容 | 初期値 |
| --- | --- | --- |
| スムージング | 手ブレと 1px 単位のカクつきをならす強さ。0 でオフ。 | 40 |
| モーションブラー | 直近何ミリ秒ぶんの動きをぼかすか。17 ms で 60fps の動画と同じ。 | 17 ms |
| 大きさ | Windows 標準のポインターを 1× とした倍率。 | 1× |
| 遅延補正 | 動きを 1 フレーム先読みして、描画カーソルの遅れを減らす。 | オン |
| サイトごとのオン・オフ | 今開いているサイトだけ止める。 | オン |

## 仕組み

- マウスの入力は `pointermove` の `getCoalescedEvents()` から全サンプルを取ります。1000Hz のマウスなら 60fps の 1 フレームに約 16 点です。
- スムージングは One Euro Filter（Casiez ほか、CHI 2012）です。縦横を別々に処理せず速さで一括して効かせるので、斜めや円の動きもゆがみません。ボタンを押している間は無効にして、ドラッグや範囲選択が実際の位置からずれないようにしています。
- ブラーは、指定した時間の範囲を等間隔に区切って軌跡上の位置を求め、WebGL2 のシェーダーで浮動小数のまま平均します。円を描けば残像も弧になります。
- 本物のカーソルは user 優先度のスタイルシートで隠します。ページ側の `!important` や Shadow DOM の中にも効きます。ページが指定したカーソルの形（I ビームや指など）は、チェックボックスの状態で切り替えるコンテナクエリ経由で読み取ります。1 回 0.2ms ほどで、ページ側からは変化が見えません。
- iframe の中でもカーソルが切れないよう、描画は一番上のページだけが行います。子フレームはサンプルを専用の MessagePort で親に送り、自分の枠の外へは動かせません。
- スクロールバーや右クリックメニューなど、Chrome が自前のカーソルを出す場所では描画を止めて本物に任せます。

## 開発用ファイル

- `node dev/engine-test.mjs`：遅れ、止まったときの行き過ぎ、円の半径の誤差を数値で確認します。
- `dev/lab.html`：円軌道でのブラーを連続フレームで表示します。
- `dev/cursor-sheet.html`：全カーソル形状を倍率ごとに並べます。
- `node dev/serve.mjs`：`dev/test/` のテストページを 127.0.0.1:8801 と :8802（別オリジンの iframe 用）で配信します。
- `node dev/make-icons.mjs`：`dev/icon.html` から `icons/` を作り直します。
